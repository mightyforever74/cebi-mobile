# TulipFleet 🚚📍

TulipFleet is a real-time fleet tracking and management system designed for mobile-first administration and IoT-driven telemetry.

## Core Features
- Live vehicle location tracking (GPS)
- Smooth map markers with heading & follow mode
- Vehicle history & route playback
- Geofence visualization and violation alerts
- Multi-tenant company structure
- Admin, Driver, and Super Admin roles

## Tech Stack
- **Mobile:** React Native (Expo)
- **Backend:** Node.js (Fastify)
- **Database:** PostgreSQL + TimescaleDB
- **Messaging:** MQTT (EMQX)
- **Maps:** Google Maps
- **DevOps:** GitHub PR workflow with AI-assisted reviews
